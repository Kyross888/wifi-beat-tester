NETWORK TESTER

1. Open this folder in VS Code (File > Open Folder).
2. Open the terminal (Terminal > New Terminal) and type:
       python network_tester.py
3. Your browser opens the Network Tester page. Click GO.
4. Press Ctrl+C in the terminal to stop it.

Files
  network_tester.py      web version (opens the page)       - no installs needed
  network_tester_cli.py  terminal-only version (the SAS ping loop with min/avg/max/jitter/loss)
  latency_test.py        the Scapy script from the SAS (needs: pip install scapy, Npcap, Administrator)

If the Wi-Fi name is blank on Windows 11: Settings > Privacy & security > Location > turn Location ON.
